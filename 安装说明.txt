dsh-draw-plugin v0.5.5 —— DeepSeek Harness 画图插件
=====================================================

【前提】
  这是 DSH（DeepSeek Harness）的插件，不是独立软件，需要先装好 DSH 才能用。

【安装】
  在任意目录（不要在插件文件夹里面）执行下面这一行：

      dsh plugin --profile web add -w "<本文件夹的完整路径>"

  例如把文件夹放在 D:\Downloads\dsh-draw-plugin，就执行：

      dsh plugin --profile web add -w "D:\Downloads\dsh-draw-plugin"

  ⚠️ -w 不能省：profile 是 pnpm 的 workspace root，不加会报
     ERR_PNPM_ADDING_TO_ROOT。

【重启】
  装完必须重启 DSH 的 web app（关掉进程再打开，或重新执行 dsh web），
  然后刷新浏览器页面；左侧边栏会出现一个铅笔图标「画图」。

  ⚠️ 升级插件时也一样：只刷新浏览器页面不够，宿主那一半是进程启动时
     加载进内存的，必须整个重启。否则面板会报「检测失败：提示词是空的」。

【使用】
  · 免费引擎不需要任何 Key：写提示词 → 选 Q版/正常 → 点生成。
  · 想更接近 2D 插画风格：切到「硅基流动」并填自己的 API Key（Kolors 等）。
  · 「固定角色」里写一段固定描述，每张图都会带上，适合反复画同一个角色。
  · ⚠️ 本机引擎的底模只认**英文标签**，中文要勾上「中文自动译成英文」；
    更好的做法是直接写英文 tag（1girl, blue long hair, white maid dress…）。
    生成后看结果下面那行「实际发送」——是中文就说明翻译没成功，那里会写原因。
  · 别写「说×××」这种要画面出字的要求，模型只会糊出假字；用 pout / angry / blush 表达情绪。

【本机引擎（可选，装一次一直用，不花 API 钱）】
  · 轻量版（默认）：本机 SD.cpp —— 面板点「一键安装」只下 29MB 引擎
    + 2GB 模型，1~3 分钟装完；N 卡 / A 卡 / 核显都能跑（走 Vulkan）。
    要挂 LoRA 就在提示词里写 <lora:名字:0.8>。
  · 完整版（默认）：本机 ComfyUI —— 一键安装约 5GB（含 CUDA 版 PyTorch）
    + 2GB 模型，10~20 分钟；换来完整节点生态、工作流、面板里选 LoRA。
  两个版本**代码完全相同**，区别只是默认选中哪个引擎，面板里随时能切换。

  · 已经自己装过 ComfyUI 的：不用重装，把「安装位置」填到你的安装目录即可
    （自装版填有 python\ 和 ComfyUI\ 的那层；官方便携包填有 python_embeded\
    的那层）。填一次会被记住。
  · 用的是 ComfyUI Desktop（桌面包）或整合包的：**不用填目录**——直接打开
    那个应用（它自己就监听 8188），回面板点「读取模型 / LoRA」就能画。

【出图目录】
  默认 $DSH_HOME/dsh-draw（Windows 是 C:\Users\<你>\.dsh\dsh-draw）。
  面板里的「保存到」可以改，改过会记住。
